# Mohd Mudassir Ansari · Portfolio

Minimalist, resume-style portfolio built with Next.js. Off-white background, dark brown text, Times New Roman throughout.

## Run
```bash
npm install
npm run dev      # http://localhost:3000
```

## Production
```bash
npm run build
npm start
```
Or import the repo on Vercel (zero config).

## Edit content
All content lives in `lib/data.js`, taken from the resume.
Each project has an empty `url` field; add the repository link to show a "Link" next to its stack.
